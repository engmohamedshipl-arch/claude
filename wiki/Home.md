# Alex West WWTP: project controls wiki

Working knowledge base for planning and quantity work on the Alexandria West Wastewater Treatment Plant. Each page records:

- the inputs used
- the decisions taken
- the results
- what is still open

Last updated 22 Oct 2026.

## Files in this repository

- `pipe-sequence-methodology/`: sequence workbook, P6 `.xer`, MS Project `.xml`, build scripts
- `estimate-boq/`: estimate BOQ workbook and take-off scripts
- `wwtp-constructability/`: earlier site constructability scaffold

All workbooks are planning tools. They are not a design, a temporary-works design or a construction approval.
