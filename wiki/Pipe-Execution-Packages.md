# Pipe execution packages (v3, 21 Oct 2026)

Source workbook: `Alex-West-Pipe-Execution-Packages-All-Lines.xlsx`, based on drawing ALEXW-MWT-MEC-00-DLU-002 Rev 03 (01.10.26, Issued for Approval).

## What it is

All 45 printed lines split into 201 work packages using the method agreed on the UG-02 pilot.

- **Package boundaries:** tie-ins at structures, short structure-to-structure connections, trench / corridor changes, and tees.
- **Planning name:** `PipeType-Line-Segment-From-To-(R start/R end)-Length`, for example `GRP-UG02-S01-PST08-EL013-(-5.10/-5.38)-13m`.
